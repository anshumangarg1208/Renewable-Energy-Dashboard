# Renewable Energy & CO₂ Analytics

A desktop dashboard built with Python, Tkinter, pandas and Pillow.

## Run

```bash
python main.py
```

Install the packages listed in `requirements.txt` in the Python environment you use to run the application. On Windows, a standard Python installation and a project virtual environment are recommended. MSYS2-managed Python environments should install packages through their own package manager or use a separate standard Windows Python installation.

## Features
- Dashboard summary cards and dataset overview
- Five supplied analysis visualizations
- Country and year indicator analysis
- Searchable dataset explorer and filtered CSV export
- Offline Natural Earth country boundaries, selected-country highlighting, coordinate marker and animated fly-to camera

The map uses bundled, simplified Natural Earth country outlines. It runs offline and is intended for data exploration, not navigation or survey-grade boundary precision.
